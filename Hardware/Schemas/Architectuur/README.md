# Architectuur

## Wat is dit?
De overzichtstekening van het hele Motio-systeem: welke onderdelen er zijn en hoe ze met elkaar verbonden zijn.

## Inhoud
| Bestand | Wat is het? |
|---|---|
| [Architectuur.drawio](Architectuur.drawio) | De bron. Open met [draw.io](https://app.diagrams.net) of de VS Code-extensie. **Pas het schema hier aan.** |
| [ArchitectuurFoto1.png](ArchitectuurFoto1.png), [ArchitectuurFoto2.png](ArchitectuurFoto2.png) | Exports van het schema, handig voor in documenten en de README |

## Onderhoud
Pas je het schema aan, exporteer dan opnieuw naar PNG en vervang de foto's. Anders loopt de afbeelding achter op de bron.
