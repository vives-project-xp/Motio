# gShield v5b

## Wat is dit?
Onderzoek naar de driverkaart (grblShield v5b) die onze drie motoren aanstuurt. Oorspronkelijk is het een shield voor Arduino; wij sluiten hem aan op de Raspberry Pi 5.
