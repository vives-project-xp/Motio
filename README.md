# Motio: Makes motion visible

## Projectbeschrijving

Het doel van dit project is om een systeem te ontwikkelen die bewegingen tastbaar en zichtbaar maakt door ze
om te zetten in fysieke tekeningen.

Het is de bedoeling dat het systeem met behulp van meerdere bewegende
elementen samen complexe patronen kan creëren, vervolgens vertaalt een
tekeninstrument deze gecombineerde beweging naar lijnen op papier.

Door parameters zoals snelheid, richting, fase en
bewegingsverhouding te veranderen, ontstaan
telkens andere visuele patronen.

## Functies/onderdelen

- **Instelbare parameters:** snelheden, richtingen en andere parameters moeten makkelijk regelbaar zijn.
- **Visualisatie:** de beweging moet gevisualiseerd worden door een tekeninstrument.
- **Preview:** indien mogelijk een preview van de ingestelde beweging weergeven op een scherm.
