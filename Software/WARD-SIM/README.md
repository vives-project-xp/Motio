# WARD-SIM

- [Sim V1](SIMV1/index.html) — oorspronkelijke live simulator.
- [Sim V2](SIMV2/index.html) — virtueel prototype met één gemeenschappelijke aandrijving.
- [Sim V3](SIMV3/index.html) — apart mechanisch prototype met drie motoren, gesloten armketen, technische 2D/3D-views en componentenlijst. Zie [ontwerp en validatie](SIMV3/README.md).

Elke versie heeft haar eigen bestanden. Open de gewenste `index.html` in een browser; er is geen installatie nodig.
